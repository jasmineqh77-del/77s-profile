## Adding a new post

Create a `.md` file under `content/posts/` and start it with these lines:

```
---
title: Post title
date: 2026-01-20
excerpt: The one-line summary shown in the list
---
```

Then just write Markdown below it. Posts are sorted newest first, and saving the file and refreshing the page is enough to see it.

## What's supported

The usual Markdown works: **bold**, *italic*, `inline code`, lists, blockquotes, images, and links.

> Blockquotes look like this.

- List item one
- List item two

Put images in `public/`, then reference them with `![caption](/image-name.png)`.

77-OS is a personal site skinned as a Windows Vista/7-era desktop — glass window frames, a glowing centered title bar, a round Start orb, a two-column Start menu. No UI framework, no component library: every control on the desktop, taskbar, Start menu, and window chrome is hand-written CSS.

01No UI framework — every control skinned by hand in CSS
02content/ vs src/ — updating the site never touches app code
03Aero glass on frames only, windows stay opaque so dragging never redraws a blur
04Boot / login / shutdown deliberately one era earlier than the desktop — contrast, not decoration

What building this took

Four decisions that look small in a screenshot but shaped how the whole thing was built and kept easy to maintain.

01 Content and code, kept apart. Every personal fact lives in content/site.ts. Adding a project or a blog post never touches src/ — the update surface a non-engineer could safely edit is the whole point.
02 Data and components, split on purpose. appMeta.ts (pure data) is separate from appRegistry.tsx (components) specifically so the window store can read app metadata without creating a circular import.
03 Designed to degrade, not to break. The Guestbook and visitor counter depend on an optional Redis connection. Without it, those two windows show an "offline" state — everything else on the site keeps working.
04 A one-pixel decision nobody asked for. Cursor hotspots were hand-recalculated so switching pointer shapes doesn't make the cursor visibly jump — the kind of detail only shows up as "this feels off" if it's wrong.
